## Описание

Учебный интернет-магазин игровой периферии (клавиатуры, мыши, гарнитуры), разработанный на Bootstrap.
Это отдельная реализация предметной области через CSS-фреймворк: вся вёрстка построена на сетке и компонентах
Bootstrap, собственный CSS минимален.


## Подключение Bootstrap

В проекте Bootstrap подключён **локально**, без CDN. Файлы фреймворка размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

Собственный `css/custom.css` подключается после Bootstrap, чтобы можно было переопределять отдельные стили.



## Реализованные компоненты и классы Bootstrap

- сетка: `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`;
- `navbar` с `dropdown`, одинаковый на всех страницах, активный пункт через `active`;
- `card` (каталог, главная, форма, блок «Другие товары»);
- `btn`, `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`;
- `nav-pills` (кнопки фильтра каталога);
- `badge` («Хит», «Новинка», «Скидка»);
- `alert` (информационные сообщения и предупреждение на карточке товара);
- `modal` (быстрая заявка с названием выбранного товара);
- формы: `form-control`, `form-select`, `input-group`, `form-check`, проверка через `needs-validation`,
  `was-validated` и `invalid-feedback`;
- `accordion` (частые вопросы на карточке товара);
- `carousel` (популярные товары на главной);
- `nav-tabs` / `tab-content` (характеристики и доставка на карточке товара);
- `toast` (уведомление об отправке формы);
- `breadcrumb`, `list-group`, `table`, `table-responsive`.




## Как проверить проект

1. Открыть `index.html` в браузере (сервер не нужен) или ссылку на GitHub Pages.
2. Пройти по меню: Главная → Каталог → Товар → Заявка → Контакты.
3. В каталоге переключить фильтр категорий, открыть «Подробнее» у любого товара.
4. Нажать «Заказать»: откроется модальное окно с названием товара. Отправить пустую форму (появятся ошибки),
   затем заполненную (появится уведомление).
5. На карточке товара переключить вкладки и раскрыть вопросы accordion.
